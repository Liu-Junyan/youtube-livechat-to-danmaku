YouTube ASS 弹幕在线转换

将YouTube Live Chat转换为ASS弹幕
兼容 libass 和 VSFilter 的 ASS 格式解析器

选项

YouTube live chat有三种emotes：频道专属、YouTube原创、标准Emoji；前两种无法在本地渲染。但即使是第三种，YouTube也以 :custom_name: 的形式表示。勾选此项将把它们转换为Unicode，以在本地渲染。
勾选此项将移除所有 :custom_name: 形式的emotes。
Noto Emoji：一种黑白Emoji字体。非Windows平台一般用libass渲染ASS字幕，但该库无法渲染彩色Emoji。所以，如需在非Windows平台渲染Emoji需勾选此项并在本地安装字体。

帮助

先用命令行工具下载聊天记录，再在本页转换为 ASS 弹幕。请使用包含 YouTube 身份验证修复的 Indigo128/chat-downloader 分支；本转换器已使用该分支下载的 JSON 验证。

  1. 安装下载工具。安装 Python、pip 和 Git 后，在你的 Python 环境中运行： 
    python -m pip install --upgrade --force-reinstall "git+https://github.com/Indigo128/chat-downloader.git"

    此命令会替换同一环境中已安装的版本。仅运行 pip install chat-downloader 会安装原版，而非上述分支；分支的命令名仍为 chat_downloader。

  2. 下载聊天 JSON。选择已结束且可查看聊天重放的 YouTube 直播，将下面的 VIDEO_ID 替换为视频 ID： 
    chat_downloader "https://www.youtube.com/watch?v=VIDEO_ID" --output chat.json

    等待下载完成，文件会保存在终端当前目录。请保留 .json 扩展名，不要使用 CSV 或复制终端输出代替。

    若 YouTube 要求身份验证，将已登录 YouTube 的浏览器 Cookies 导出为 Netscape cookies.txt 格式，再运行：

    chat_downloader "https://www.youtube.com/watch?v=VIDEO_ID" --cookies cookies.txt --output chat.json

    Cookies 包含登录信息，请勿分享，也不要在本页选择 Cookies 文件。下载失败时，请确认视频有聊天重放，并检查当前命令使用的是上述分支。

    只想快速测试？在下载命令末尾加上 --start_time 0 --end_time 300 --max_messages 500，即可下载前 5 分钟内最多 500 条消息；时间戳仍对应原视频。

  3. 转换并播放。先设置上方的表情选项，再点击“上传JSON文件”并选择 chat.json。转换在浏览器中完成，并自动下载 chat.ass。用支持 ASS 的播放器打开对应视频，再加载该字幕文件。

    仅转换视频开始后的普通文字消息；移除表情后为空的消息，以及无法安排显示位置的消息会被跳过，因此输出条数可能少于原始聊天条数。
